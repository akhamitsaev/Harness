# Skill: чек-лист валидации цитат

Reviewer должен проверить:

1. source_quote действительно присутствует в предоставленном source text.
2. Цитата непосредственно поддерживает извлечённый outcome/effect, а не просто относится к теме статьи.
3. Числа, n, phase и другие конкретные значения не домыслены.
4. PMID/DOI/NCT/URL считаются доверенными только если они пришли из provenance, приложенного Python-кодом.
5. Если claim сильнее цитаты - запись должна быть отклонена и возвращена extractor с конкретным feedback.
6. Если источник является регистрацией исследования без результатов, нельзя подтверждать efficacy только по primary outcome.
