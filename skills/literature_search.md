# Skill: поиск литературы

1. Строй два независимых поисковых трека для одного заболевания:
   - mitochondrial: митохондриально-таргетные вмешательства;
   - standard: традиционный стандарт лечения / стандартная симптоматическая терапия.
2. Для PubMed включай заболевание и конкретные терапевтические термины; не делай запрос слишком общим.
3. Для ClinicalTrials.gov указывай заболевание и, если возможно, intervention terms.
4. Временное окно задаёт Root-оркестратор: 3-5 лет.
5. Не подменяй стандарт лечения митохондриальной терапией только потому, что она уже применяется в практике.
6. Если стандарт лечения неоднозначен, укажи наиболее общепринятый comparator и явно сформулируй это в поле standard_of_care.
7. Поисковик планирует поиск, но не делает выводов об эффективности.
