# Skill: шкала уровней доказательности

Выбирай наиболее сильный тип дизайна, который прямо подтверждается источником:

1. systematic_review - систематический обзор / метаанализ.
2. RCT - рандомизированное контролируемое исследование на людях.
3. controlled_trial - контролируемое клиническое исследование без явной рандомизации.
4. clinical_trial - интервенционное исследование на людях, которое нельзя уверенно отнести к предыдущим категориям.
5. observational - когорта, registry, case-control и другие наблюдательные исследования.
6. case_series - серия случаев / case report group.
7. preclinical - животные, клетки, organoids, модели заболеваний и другие доклинические данные.
8. other - ничего из перечисленного.

Уровень доказательности:
- high: несколько качественных RCT / систематический обзор согласованных клинических данных;
- moderate: RCT с ограничениями либо качественное контролируемое клиническое исследование;
- low: небольшие clinical trials или наблюдательные данные;
- very_low: case series, слабая/неполная клиническая информация;
- preclinical: только доклиника;
- unclear: данных недостаточно.

Не повышай уровень доказательности из-за положительного результата.
